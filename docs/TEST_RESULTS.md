# Методика и результаты тестирования

## Юнит-тесты

`./gradlew :app:testDebugUnitTest`: сборка слов из токенов, выравнивание слов и говорящих,
JSON-экспорт, ресемплер, промпты и защита LLM от изменения слов.

## Проверка моделей (Mac, sherpa-onnx Python 2.0.1, 4 потока)

Синтетический диалог двух говорящих (TTS Milena, второй голос со сдвигом высоты), 31 с, 6 реплик.

| Метрика | Результат |
|---|---|
| Диаризация | 6/6 реплик, 2 говорящих определены автоматически, границы ±0.2 с |
| Распознавание | 1 ошибка: «мышиной обороны» → «Мышины Бороны»; «три» → «3» |
| RTF (Mac M-series, VAD+ASR+диаризация) | ≈ 0.17 |

Результаты на устройстве и эмуляторе: `artifacts/test-results/results.csv`.

## Эмулятор (Mac Apple Silicon, AVD Pixel 8, Android 16 / API 36 arm64, 4 ядра, 6 ГБ RAM)

Тот же диалог `dialog_cats.wav` (31 с), импорт через системный выбор файлов.

| Режим | Обработка | RTF | Говорящих | Реплик |
|---|---|---|---|---|
| ASR + диаризация (по умолчанию) | 8.1 с | 0.26 | 2 / 2 | 6 / 6 |
| + LLM-редактура пунктуации | 17.2 с | 0.56 | 2 / 2 | 6 / 6 |

Отклонение начала реплик от эталона: 20–110 мс. Протокол Qwen3-1.7B строится
за ~5 с после показа расшифровки и не влияет на RTF.

## Песня (v3): распознавание текста поверх музыки

Тестовая песня 2:01, русский рэп с музыкой, эталон — текст песни (198 слов).
Метрика: сходство = 1 − WER, без учёта регистра и пунктуации, пометки [Припев] убраны.

| Вариант | Сходство |
|---|---|
| Версия 1 приложения (без обработки музыки) | 33.3% |
| GigaAM + VAD, без отделения вокала | 51.0% |
| Qwen3-ASR-0.6B на отделённом вокале | 57.6% |
| Spleeter 2stems → GigaAM | 50.5% |
| UVR MDXNET 1_9703 → GigaAM | 69.7% |
| DPDFNet (речевой шумодав) на песне | 11.6% — поэтому на музыке он отключается |
| **UVR-MDX-NET-Voc_FT (стерео 44.1 кГц, куски 5.9 с) → GigaAM, VAD 0.6/30 с** | **80.8% (Mac), 82.8% (приложение на эмуляторе)** |

Отделение вокала требует полнополосного стерео: при подаче моно — 72.7%, при подаче 16 кГц — 61.6%.
Обработка песни на эмуляторе — 5 мин 45 с (RTF ≈ 2.9), пиковая память ~2.5–4.6 ГБ.
Основные оставшиеся ошибки: «щас» → «сейчас», английские вставки (WET, Dolce Gabbana), «на ней» → «не».
